Từ 0 tới Senior Backend

Xây một nền tảng e-learning thật — để nhận freelance/remote và tự ship sản phẩm riêng.

Chế độ: dự án song song — ĐANG BẬT. Không có thư mục "practice" bỏ đi. Sân tập chính là dự án đích: elearning-api. Mỗi bài đắp thêm một mẩu chạy được vào nó — cột bên phải mỗi dòng ghi rõ bài đó thêm gì.

Đích đến: Bài 48 dự án lên internet thật; Bài 56 nó thành portfolio đưa cho khách.
Ngoại lệ trung thực: 7 bài đánh dấu nền ở cột phải (01–04, 07, 24, 55) không đắp thẳng vào API — chúng dạy bản chất bằng cách cho bạn tự viết lại thứ mà framework che giấu, và sống ở thư mục lab/. Tôi nói thẳng còn hơn giả vờ mọi bài đều "ra sản phẩm".

Nguyên tắc: luôn hỏi vì sao và đánh đổi là gì. Mọi khẳng định đều dẫn link tới docs chính chủ.

Module 1

Bản chất backend & Node runtime

Framework chỉ là lớp bọc. Nếu không hiểu HTTP và event loop, bạn sẽ mãi copy-paste NestJS mà không biết vì sao hệ thống chậm hay chết. Module này bạn viết server không dùng framework, trong lab/.

  • Bài 01 HTTP thực sự là gì — tự viết web server bằng node:http thuần nền · lab/
  • Bài 02 Request & Response: method, status code, header, body nền · lab/
  • Bài 03 Event loop & non-blocking I/O — vì sao Node hợp việc I/O nền · lab/
  • Bài 04 Async trong Node: callback → Promise → async/await, và lỗi đi đâu nền · lab/
  • hoãn Tiến trình server: env, tín hiệu tắt, graceful shutdown kéo vào khi API cần deploy
  • hoãn Thiết kế REST API: resource, verb, status, versioning, idempotency kéo vào khi API đủ lớn
  • 📄 Ôn Cheat-sheet: Node core & NestJS cải thiện gì gom Bài 01→06 · in được
Module 2

NestJS — kiến trúc và vì sao có nó

Sau khi tự tay chịu khổ ở Module 1, bạn sẽ thấy rõ Nest giải quyết vấn đề gì. Module này dựng bộ khung mà các bài sau đắp code vào — và ra endpoint thật đầu tiên.

Module 4

Auth & bảo mật

Đúng các tính năng bạn đặt hàng: đăng ký, đăng nhập, đăng xuất, quên mật khẩu, đổi mật khẩu — nhưng làm cho đúng, không phải làm cho chạy. Đây cũng là phần khách freelance soi kỹ nhất.

  • Bài 22 Lưu mật khẩu: vì sao bcrypt/argon2, vì sao không phải SHA-256 → bảng User + hash
  • Bài 23 Đăng ký + xác thực email (token dùng một lần, có hạn) → POST /auth/register
  • Bài 24 JWT bản chất: header.payload.signature — tự ký & verify bằng tay nền · lab/
  • Bài 25 Access token + Refresh token rotation — lưu ở đâu và vì sao → login / refresh / logout
  • Bài 26 Guard & Passport strategy: gắn auth vào route trong Nest → route được bảo vệ
  • Bài 27 RBAC: student / instructor / admin — phân quyền không rối → phân quyền 3 vai trò
  • Bài 28 Quên mật khẩu & đổi mật khẩu an toàn (thu hồi session cũ) → forgot/change password
  • Bài 29 OWASP cho API: rate limit, CORS, helmet, mass assignment, injection → API được bọc giáp
Module 5

Nghiệp vụ e-learning & thanh toán

Giỏ hàng, mua khoá học, thanh toán. Đây là phần "đụng tới tiền" — nơi bug không chỉ khó chịu mà còn tốn tiền thật, nên là phần chứng minh năng lực mạnh nhất trong portfolio.

  • Bài 30 Giỏ hàng & Order: state machine (pending → paid → refunded) → API giỏ hàng + đơn
  • Bài 31 Tích hợp cổng thanh toán: checkout flow đúng chuẩn → tạo link thanh toán
  • Bài 32 Webhook: verify chữ ký, idempotency, retry — vì sao nó chạy 2 lần → webhook chống trùng
  • Bài 33 Enrollment & theo dõi tiến độ học sau khi thanh toán → ghi danh + tiến độ
