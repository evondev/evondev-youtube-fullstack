4xx thì bạn ngủ tiếp. 5xx thì bạn dậy sửa. Đặt sai mã ở đây là tự phá hệ thống báo động của chính mình.

3. node:http — cốt lõi

server tối giản + 3 điều phải nhớ 
import { createServer } from 'node:http';

const server = createServer(async (request, response) => {
  // (1) request.url la CHUOI THO, dinh ca query -> phai tach
  const url = new URL(request.url, `http://${request.headers.host}`);
  url.pathname;                      // '/courses'
  url.searchParams.get('level');    // 'beginner' | null (KHONG phai undefined)

  // (2) body la STREAM, khong co san. Day chinh la "body parser".
  let raw = '';
  for await (const chunk of request) raw += chunk;
  try { JSON.parse(raw); } catch { /* PHAI bat, khong la CHET CA SERVER */ }

  // (3) MOI nhanh deu phai ket thuc response, khong la client treo
  response.writeHead(200, { 'Content-Type': 'application/json; charset=utf-8' });
  response.end(JSON.stringify({ ok: true }));
});

server.listen(3333);
NhớVì sao
request.url ≠ đường dẫnDính query string. '/ping?a=1' === '/ping' là false
request.body là undefinedmethod/url ở dòng đầu đã tới; body tới sau và có thể rất lớn → Node đưa stream
Body 5MB → ~82 khúcSố khúc đổi mỗi lần chạy — đừng bao giờ giả định "về một lần"
Quên response.end()Client treo, server vẫn "xanh" — nguy hiểm hơn crash vì monitoring không thấy gì
writeHead rồi không đổi đượcHeader đã lên dây → ERR_HTTP_HEADERS_SENT. Mọi kiểm tra phải làm trước

@Injectable()

    if (!found) throw new NotFoundException('...');  // -> 404 tu dong
  }

// courses.controller.ts — CUA VAO HTTP
@Controller('courses')

  constructor(private readonly coursesService: CoursesService) {}  // DI

  @Get(':id')
  findOne(@Param('id', ParseIntPipe) id: number) { ... }
}

// courses.module.ts — GOM NHOM
@Module({ controllers: [CoursesController], providers: [CoursesService] })

// app.module.ts — dang ky nhom voi ung dung
@Module({ imports: [CoursesModule] })

🔎 DI trong một câu

Bạn khai báo mình cần gì, không tự đi lấy. Nest đọc providers để biết nó được phép tạo gì, đọc constructor để biết ai cần gì, rồi lắp vào. Mặc định một thể hiện dùng chung — quan trọng khi service giữ kết nối database. Lợi ích thật: đổi ruột (mảng → Postgres) mà controller không sửa một chữ.

8. Validation — chặn ở biên

npm install class-validator class-transformer 
// dto/create-course.dto.ts — phai la CLASS (interface khong mang duoc decorator)
export class CreateCourseDto {
  @IsString({ message: 'title must be a string' })
  @MinLength(3, { message: 'title must be at least 3 characters' })
  title: string;

  @IsIn(['beginner', 'advanced']) level: string;
  @IsInt() @Min(0)              price: number;
}

// main.ts — bat MOT LAN, ap cho moi route
app.useGlobalPipes(new ValidationPipe({
  whitelist: true,             // cat bo truong khong khai bao
  forbidNonWhitelisted: true,  // co truong la -> 400 luon
  transform: true,             // JSON tho -> the hien class
}));
